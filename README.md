# auto-rebaser-sandbox

Throwaway repo for live testing the auto-rebaser Chrome extension.

Each PR in this repo demonstrates a Phase-2 automation:
- Story 2.5 — auto-rebase behind PRs
- Story 2.6 — auto-delete merged branches
- Story 2.7 — auto-enable auto-merge
- Story 2.8 — auto-resolve obsolete review threads
- Story 2.9 — auto-dismiss stale PR notifications
